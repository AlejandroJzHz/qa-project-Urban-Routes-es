## Pruebas para el parámetro la funcionalidad de Urban Routes al pedir un taxi
- Necesitas tener instalados los paquetes pytest y Selenium para ejecutar las pruebas.
- Las pruebas son para el funcionamiento básico de pedir un taxi en Urban Routes
- Ejecuta todas las pruebas con el comando pytest main.py.
- Las pruebas fueron hechas en PyCharm usando integración de Selenium para la búsqueda e interacción con elementos del sitio web
- En la versión actual Urban Grocers permite incorrectamente crear un kit con un nombre fuera de los parámetros indicados de longitud  mínima y máxima y cuando se usan valores de un tipo diferente a texto.
